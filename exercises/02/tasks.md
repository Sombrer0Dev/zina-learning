# Задания

Три связанные таблицы создаются из `schema.sql`:

- `students(id, name)`
- `courses(id, title, hours)`
- `enrollments(id, student_id, course_id, grade)` — связывает студента и курс, хранит оценку (может быть `NULL`, если ещё не выставлена)

Обрати внимание: Егор (студент) не записан ни на один курс, а История (курс) — курс, на который никто не записался. Это специально, чтобы увидеть разницу между `INNER JOIN` и `LEFT JOIN`.

## 0. Повторение урока 1

Эти два задания не используют `JOIN` — просто разминка на `SELECT`/`WHERE`/`ORDER BY`/`LIMIT` и агрегатные функции из прошлого занятия, на новой схеме.

0.1. Выведи названия всех курсов, отсортированные по `hours` по убыванию.

0.2. Посчитай, сколько записей в `enrollments` ещё не имеют выставленной оценки (`grade IS NULL`).

## 1. INNER JOIN

1.1. Выведи имя студента и название курса для каждой записи о зачислении (используй `JOIN` таблиц `enrollments`, `students`, `courses`).

1.2. Выведи имя студента, название курса и оценку только там, где оценка уже выставлена (`grade IS NOT NULL`).

1.3. Выведи названия курсов, на которые записана студентка "Аня".

## 2. LEFT JOIN

2.1. Выведи имя каждого студента и название курса, на который он записан — включая студентов, которые ни на один курс не записаны (для них вместо названия курса должен быть `NULL`).

2.2. Выведи имена студентов, которые не записаны ни на один курс.

2.3. Выведи названия курсов, на которые пока никто не записался.

## 3. GROUP BY и агрегатные функции

3.1. Для каждого студента посчитай, на сколько курсов он записан (включая тех, у кого 0 курсов). Выведи имя студента и количество курсов.

3.2. Посчитай средний балл по каждому курсу (среди уже выставленных оценок). Выведи название курса и средний балл.

3.3. Посчитай, сколько оценок (не `NULL`) выставлено по каждому курсу. Выведи название курса и количество оценок.

3.4. Для каждого курса найди максимальный и минимальный выставленный балл одним запросом.

## 4. HAVING

4.1. Выведи названия курсов, средний балл по которым (среди выставленных оценок) не меньше 4.

4.2. Выведи имена студентов, которые записаны на 2 и более курса.

4.3. Объясни словами (без SQL): чем `HAVING` отличается от `WHERE` — почему нельзя написать `WHERE AVG(grade) >= 3`?

## 5. Комбинированные запросы

5.1. Выведи название курса и средний балл по нему (только для курсов с хотя бы одной оценкой), отсортировав по среднему баллу по убыванию.

5.2. Выведи имя студента и количество записей, где оценка ещё не выставлена (`grade IS NULL`), но только для тех студентов, у кого такое есть хотя бы раз.
