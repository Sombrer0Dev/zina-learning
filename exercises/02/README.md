# Упражнения — Урок 2. GROUP BY и JOIN

## Подготовка

```bash
sqlite3 school.db < schema.sql
sqlite3 school.db
```

Это создаст таблицы `students`, `courses` и `enrollments` и заполнит их тестовыми данными: 6 студентов (один без единого курса), 4 курса (один без единого студента) и 9 записей о зачислении (две из них — без выставленной оценки).

## Как работать

Открой `tasks.md`, выполняй задания по порядку прямо в консоли `sqlite3`. Если застрял_а — подсмотри в `solutions.sql`, но сначала попробуй сам_а.

После завершения файл базы можно удалить:

```bash
rm school.db
```

## Автопроверка

Впиши свои запросы в `answers.sql` — каждый под соответствующей меткой (`-- 2.3` и т.д.), один запрос на задание. Затем запусти:

```bash
python3 check.py
```

Скрипт выполняет твой запрос и эталонный запрос на одной и той же базе и сравнивает результаты через `assert`. Для каждого проваленного задания выводится, что ожидалось и что получилось.
