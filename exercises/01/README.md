# Упражнения — Урок 1. Введение в SQL

## Подготовка

```bash
sqlite3 school.db < schema.sql
sqlite3 school.db
```

Это создаст таблицу `students` и заполнит её тестовыми данными (12 строк, в том числе две с `grade = NULL`).

## Как работать

Открой `tasks.md`, выполняй задания по порядку прямо в консоли `sqlite3`. Если застряла — подсмотри в `solutions.sql`, но сначала попробуй сама.

После завершения файл базы можно удалить:

```bash
rm school.db
```

## Автопроверка

Впиши свои запросы в `answers.sql` — каждый под соответствующей меткой (`-- 2.3` и т.д.), один запрос на задание. Затем запусти:

```bash
python3 check.py
```

Скрипт выполняет твой запрос и эталонный запрос на одной и той же базе и сравнивает результаты через `assert`. Для каждого проваленного задания выводится, что ожидалось и что получилось.

В самом SQL (и в SQLite в частности) нет оператора `ASSERT` — ближайшие аналоги (`CHECK`-ограничения, `RAISE()` в триггерах) работают только на уровне схемы или триггеров, а не для сравнения результата произвольного запроса. Поэтому проверка сделана в Python, через встроенный модуль `sqlite3` и обычный `assert`.
