# Задания

Таблица `students(id, name, grade)` создаётся из `schema.sql`.

## 1. CREATE TABLE

1.1. Напиши `CREATE TABLE` для таблицы `courses` с полями:
   - `id` — первичный ключ;
   - `title` — название курса, обязательное текстовое поле;
   - `hours` — количество часов, число с плавающей точкой.

## 2. SELECT и WHERE

2.1. Выведи всех студентов (все столбцы).

2.2. Выведи только `name` и `grade` всех студентов.

2.3. Выведи студентов с `grade >= 4`.

2.4. Выведи студентов, у которых `grade` строго меньше 3 или строго больше 4.5.

2.5. Выведи студентов, чьё имя начинается на букву "А" (используй `LIKE`).

2.6. Выведи студентов с `grade` в диапазоне от 3 до 4 включительно (используй `BETWEEN`).

## 3. ORDER BY и LIMIT

3.1. Выведи всех студентов, отсортированных по `grade` по убыванию.

3.2. Выведи имена трёх студентов с самым высоким `grade`.

3.3. Выведи двух студентов с самым низким `grade` (не считая тех, у кого `grade` не указан).

## 4. NULL

4.1. Выведи студентов, у которых `grade` не указан.

4.2. Выведи студентов, у которых `grade` указан (не `NULL`).

4.3. Объясни словами (без SQL): почему `WHERE grade = NULL` не найдёт ни одной строки с `grade IS NULL`.

## 5. Агрегатные функции

5.1. Посчитай общее количество студентов.

5.2. Посчитай, у скольких студентов указан `grade` (подсказка: `COUNT` с конкретным столбцом игнорирует `NULL`).

5.3. Найди средний `grade` по всем студентам, у кого он указан.

5.4. Найди максимальный и минимальный `grade` одним запросом.

5.5. Посчитай сумму всех `grade`.
